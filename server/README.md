# 本地只读内容预览

`yarn preview:local` 在 `127.0.0.1` 提供根目录 `out/` 和公开读取 API，默认端口为 4392，可通过 `LIFEOS_PORT` 修改。此服务用于本地预览，不提供管理员身份、登录、写入或生产发布能力。

公开读取接口为 `GET/HEAD /api/profile`、`/api/projects` 和 `/api/projects/:id`。旧 `/api/session`、`/api/admin` 及其子路径对所有请求方法返回 404；服务不处理 Cookie、角色或 CSRF 头，不设置会话 Cookie。所有访问者得到相同的公开内容。

启动时若存在 `server/.runtime/data/content.json`，只加载其已发布作品快照，并对 profile、作品字段和中英文正文逐层应用公开白名单。草稿、私有备注、管理字段与私有媒体不会自动公开；数据文件或公开字段格式错误会终止启动。没有内容文件时使用已提交的 `server/content/seed.json`，不会创建运行目录、内容文件或密钥。旧密钥文件不读取、不修改；研究原型数据不读取、不迁移。

`/media/:id` 只提供已发布快照引用的 PNG、JPEG 或 WebP 文件，保留原有大小和签名边界，并拒绝符号链接或越界路径。静态文件仅从指定 `out/` 目录读取，不跟随指向目录外的符号链接。图片签名检查不等于完整图片解码。内容投影在启动时固定；外部更新已发布快照后，需要重新启动相应本地预览才能加载新内容，不会由本服务修改数据或部署上线。

`yarn test:server` 使用临时合成数据测试退休接口、身份无差异、文件不变及公开媒体边界，不使用个人运行目录或真实密钥。`server/test/serve.mjs` 直接读取公开 seed，不创建测试 runtime；默认端口仍为 4392，验收可以使用 `LIFEOS_PORT=4494 node server/test/serve.mjs`。已有预览服务须先核实占用，不能为测试直接重启其他端口的服务。
