# 综合看板验收矩阵

2026-10-18。此表定义后续开发必须观察到的结果；本次研究阶段没有运行产品或设备验收，不预勾选通过。每次实施报告记录提交、数据用途、模式、真实执行命令、结果及未覆盖项。专题矩阵补充领域细节；存在候选语义差异时以 [架构契约](architecture.md) 为准。

| 编号 | 输入/操作 | 必须观察到的结果 | 证据层 |
| --- | --- | --- | --- |
| D01 | 无参数进入；从商店/菜单/深链接多次打开 | 仍默认桌面；只一个Dashboard实例；最小化可恢复 | 浏览器 |

| D07 | 模块关闭、指标开启；新增未知字段 | 上级关闭生效；新字段/指标默认私有；不泄露隐藏数量 | 单元+服务 |
| D08 | 日历T=2026-10-18，H3/D7、H1/D7、H3/D1 | 分别10/9–11、10/11、10/15–17；开始包含，截止次日排除 | 固定时钟纯函数 |
| D09 | 滚动N=2026-10-18T12Z，h72/d168；语言/访客时区改变 | 范围[10/8T12Z,10/11T12Z)；语言/访客时区不改授权 | 单元+服务 |
| D10 | 1日、3日、1日历月、全部/关闭；月末/闰年/DST | 日历与滚动不混用；1月不当30天；日界线采用当地日期首个真实时刻。New_York的C=2026-04-08 02:30回退月得到03-08 03:30（07:30Z）；C=2026-12-01 01:30回退月得到11-01 01:30后一次（06:30Z）；23/25小时与跳过日期按契约处理 | 单元 |
| D11 | 睡眠/活动跨截止，日聚合含禁止样本 | 默认排除跨窗整体；支持裁剪时仅按合法样本重算，标实际覆盖 | 单元+服务 |

| D13 | 私有哨兵值遍历current/history/summary/search/export/media/errors | 完整响应/产物无禁止字段或日期；金额、数量、metadata不能反推隐藏记录 | 真实服务+产物检查 |
| D14 | 收紧政策、旧URL、在途查询/导出、CDN缓存、断网 | 动态受控新请求按当前政策拒绝，记录传播上限；不无限提供敏感旧副本 | 集成/部署 |
| D15 | 要求自动撤回的敏感记录静态导出；archive误作published | 导出明确拒绝；不以expiresAt或前端隐藏放行 | 导出集成 |
| D16 | 合法固定公开包新发布移除条目 | 新受控产物移除；明确旧Git/发布/CDN/下载副本不能保证回收 | 发布演练 |
| D17 | 401过期、显式注销/关闭、两窗口并发 | 401清查询/图表缓存并暂停私有显示/写入，草稿只保留隔离编辑内存待重新验证；显式注销/关闭先经未保存保护再处理草稿；409可核对重开；不持久化敏感草稿 | 服务/浏览器 |
| D18 | 原生HTML/脚本/预览尝试借用管理会话 | 以真实执行核验隔离，不能将HttpOnly/CSRF或隐藏入口作为隔离证据 | 来源隔离专项 |
| D19 | 文件版本错误、重复ID、超限/损坏JSON/XML/附件、路径穿越 | 明确拒绝、不部分覆盖原数据；真实解析器和媒体验证 | 导入/服务 |
| D20 | 重启、备份导入新目录、schema回退 | 稳定ID/版本/政策/记录保持；凭据会话不迁移；回退不放宽隐私 | 恢复演练 |

| 编号 | 故障/操作 | 结果 |

## 执行规则

本次仅文档：检查来源、链接、时间样例、独立审查与 `git diff --check`。产品实施时按 AGENTS 的依赖顺序选择检查：

```sh
yarn build
yarn lint
yarn test:unit
yarn test:server
yarn playwright install chromium
yarn e2e:product
```

涉及公开导出时，另在隔离工作区运行 `node scripts/product/build.mjs --public`、lint/unit/server 和 `PUBLIC_DEPLOYMENT=1 yarn playwright test --config=playwright.public.config.ts`。不得重建活动预览使用的out或复用其runtime。

浏览器至少覆盖普通桌面视口、1024×768和390×844窗口环境下的实际OS行为，以及受影响窗口缩放；这些是自动化视口证据，不冒充真实手机/iPad。真实设备、浏览器/系统版本、地区网络、数据源版本和未测能力在交付中逐项说明。

性能不预写虚构SLA。实现后记录来源/主机/序列数、查询窗、返回字节、采样频率、adapter延时与绘图耗时；确认预算再形成数值门槛。所有失败/跳过/未执行分别记录，不能以旧CI或纯公式测试替代权限、恢复和真实设备证据。
