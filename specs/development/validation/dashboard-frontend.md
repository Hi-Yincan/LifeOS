## 网络、存储与证据边界

请求监听在打开 Dashboard 之前安装。覆盖挂载、活动保存、五模块导航与访客预览时，只允许既有 OS 静态文件 `/.index/fs.9p.json`、`/content/projects.json`、`/Users/Public/Desktop/desktop.ini` 的 fetch/XHR；其余请求列表为空，没有 WebSocket。公开回归另外验证 API 不可用和私有字段不出现在公开快照。

同一流程前后的 localStorage/sessionStorage 内容相同；保存后刷新及原生关闭重开恢复初始数据。Dashboard 源码没有 fetch、XMLHttpRequest、WebSocket、sendBeacon、localStorage、sessionStorage 或 indexedDB 调用。这些证据针对本应用示例数据；没有声称穷尽验证 OS 自身全部 IndexedDB/文件系统持久化行为。
