## 退役边界的实际证据

- 系统设置只有语言偏好与时区。英文和中文均没有维护折叠区、密码/密钥框、登录/退出、管理员/访客角色提示；Portfolio 列表和详情也没有管理按钮、编辑表单或管理状态。
- 使用合成旧格式 `hyc_concept_session` 和 `role=admin` cookie 后重新加载，Portfolio 的 16 项作品标题与匿名读取相同。浏览器确实保留了测试 cookie，但公开内容 fetch 请求均为 GET，未携带 Cookie 或 X-CSRF-Token，也没有 `/api/session` 或 `/api/admin` 请求。
- 同样的合成 cookie 不改变看板内容：六个会员、六个服务、四个服务器和步数/心率/睡眠/体重四项值逐项相同，没有新增/编辑/付款/续费/公开范围入口。
- API 请求直接附带合成 Cookie、Authorization、X-Role 和 X-CSRF-Token，读取结果与匿名完全相同；写入尝试前后再次读取相等，公开响应不含 draft、version、published、updatedAt 或 privateNote。
- 浏览器请求层实际检查七类旧路径：session、admin 根、项目列表、实体、发布、下架和图片上传；每类分别检查 GET、HEAD、POST、PATCH、DELETE，共 35 个组合，所有响应均不设置 cookie。

| 旧管理路径请求      | 本地只读服务 | 公开静态测试服务器          |
| ------------------- | ------------ | --------------------------- |
| GET、HEAD           | 404          | 404                         |
| POST、PATCH、DELETE | 404          | 501，静态服务器未实现该方法 |

公开服务器使用既有 Python `SimpleHTTPRequestHandler`。501 是实际静态测试结果，没有修改测试服务器来伪造与本地相同的状态码，也不把它当作线上 Pages 状态码保证。两种模式均没有可用写接口。本地服务单测还检查 Node 所列全部 HTTP 方法、编码路径和跨来源请求，统一返回 404；该更完整的方法范围不混同于浏览器层的 35 个组合。

- 服务单测对合成既有 runtime 仅投影 published 对象，并对项目、双语正文、profile 嵌套字段分别白名单处理；未发布记录、草稿和嵌套私有标记不可读。缺失目录或空目录保持不变，非法已存内容明确失败，不自动修复或退回种子数据。
- 只有已发布引用、合法类型/大小且不越界的媒体可读；草稿图片、未引用文件、伪造扩展名、符号链接和越界静态文件不可读。读写尝试前后的合成文件内容、权限和修改时间相同。
- 公开快照仍有 16 项作品，精选保持 AIPM、VideoNote-MCP、Agentero；原服务种子与本地密钥路径不存在于公开产物中。
