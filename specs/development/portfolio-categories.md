# 作品集分类调整

2026-10-18，关联作品集议题 #15。本文记录 `feat/portfolio-categories` 的实现与验证；用户已验收通过，并授权提交、合入本地与远程 main 及清理任务资源。

作品栏目改为「产品 / 工具 / 贡献 / 其他」，初始不选中任何分类。点击分类筛选，再次点击取消；取消分类保留搜索词，空结果的「全部作品」按钮同时清除搜索和分类。中英文、卡片、详情和管理编辑器使用一致的分类名称。

数据沿用 `project` 表示产品，新增 `tool` 表示工具，`contribution` 表示贡献，`other` 表示其他。后续按用户要求扩展为 16 项公开作品，并取消 Multica 的精选标记，详见 [GitHub 作品归类与精选调整](github-portfolio-classification.md)。未覆盖已有本地运行数据。

## 首轮三分类验证

- Node 22.23.3 / Yarn 1.22.22 下独立工作区产品构建通过，站点资源审计通过。
- `yarn lint`、Prettier 检查与 `git diff --check` 通过。
- 单元测试 30 项、服务测试 14 项通过。服务测试覆盖三分类修改、发布前快照不变、发布后分类更新和非法分类拒绝。
- 作品集相关 Playwright 验证共 4 项通过：桌面启动规则、项目详情深链接、分类切换/取消/搜索/键盘、管理编辑器草稿/发布/下架。新增筛选用例首次因导航按钮名称包含数量而定位失败，改用现有「Explore work」按钮后重跑通过。
- ego-browser 核对中文栏目与卡片名称、默认全部状态，并在 390 × 844 视口检查三个分类按钮均位于可见区域。英文交互由 Playwright 验证。
- ego-browser 截图接口超时，因此未完成截图视觉验收；未进行手机或 iPad 真机验证，未执行全量原生 App 回归。

验收期间独立预览使用端口 4397，数据位于任务工作区的 `server/.runtime/`。清理时停止任务服务并备份运行数据。原有 4391、4392 及其他任务服务保持运行。测试服务使用临时数据与端口 4398，测试结束自动关闭。
