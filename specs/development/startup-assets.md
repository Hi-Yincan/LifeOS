# 首屏头像资源优化

关联 Issue：[#54](https://github.com/Hi-Yincan/LifeOS/issues/54)。延续[资源就绪启动屏](resource-ready-boot.md)，优化实际下载量。

## 范围与实现

保留 `public/System/LifeOS/avatar.png` 原图及透明圆形裁剪，SHA256 为 `c8a30fd039ec2e8320b39fe083d5e40ee3650825211bf9a5d3517ee1a601a8c1`。`lifeos.json` 中的 `icon` 继续用于分享图，新增 `appIcon` 与 `favicon` 指向轻量显示资源。

应用图标沿用 OS 的 16 / 32 / 48 / 96 / 144px 规则，提供 WebP 和 PNG 回退。桌面、开始菜单、进程注册、窗口/任务栏与商店共享同一图标，作品集概览与「关于我」复用原生 Icon 的尺寸与 DPI 选择。favicon 固定使用 48px PNG，保持头像及原有动态窗口标题。默认浏览和作品集内容不再下载高清头像；分享元数据保留原图。

旧 `portfolio.svg` URL 保留独立可显示的兼容资源，嵌入 144px PNG，供已保存的旧快捷方式继续显示。所有图像均由原图确定性缩放、编码，没有重新生成或改变人物内容。生成工具使用 libwebp 的 `cwebp` / `dwebp`，普通构建只消费已提交的资源，不新增安装依赖。

重新生成命令：

```sh
node scripts/product/generate-site-icons.mjs
```

构建审计检查 favicon、各尺寸位图和兼容 SVG 的体积预算，以及桌面/开始菜单快捷方式与配置的一致性。浏览器回归检查 1× / 2× / 3× 的实际选图、固定 favicon、作品集概览/关于页不请求高清资源；启动门禁、深链接与按需加载保持原有规则。

## 体积

| 资源            |                             优化前 |                                       优化后 |
| --------------- | ---------------------------------: | -------------------------------------------: |
| 默认作品集图标  | SVG 原始 512,469 B；gzip 约 386 KB | 48px WebP 888 B；96px 2,176 B；144px 3,664 B |
| favicon         |                 原始 PNG 384,251 B |                             48px PNG 3,288 B |
| 旧 SVG 兼容入口 |                     原始 512,469 B |                 原始 23,036 B；gzip 17,396 B |

上一轮约 0.75 MB 的估算来自主页面 Resource Timing，不完整覆盖浏览器 favicon 和 worker 内部请求，不能视为完整浏览器下载量。本轮比较分别记录页面资源、favicon 和构建体积，避免混用口径。

## 验证

2026-10-21 使用 Node 22.23.3、Yarn 1.22.22、libwebp 1.6.0 与真实 Chromium 验证。本地读取模式和隔离 Pages 模式均通过构建、资源审计、lint、89 项单元测试及 15 项服务测试；完整浏览器回归分别为 65 / 67 项，包含新增的 1× / 2× / 3× 实际选图检查。已有启动门禁、深链接、中文/英文、三个视口和原生应用回归均保留。已复核真实窗口截图；旧 SVG 在浏览器中独立解码成功，四角透明、中心不透明，所有位图尺寸及 alpha 也已核验。

受控对照使用同一浏览器、1280×720、2×DPI，两个本机 HTTP 静态服务均启用 gzip，禁用缓存，设置 200,000 B/s 下载与 100 ms 延迟，交替测量优化前后各三次。基线为优化前保留的同源码本地读取模式构建，优化版为当前本地读取模式构建。

| 中位数                        |    优化前 |    优化后 |
| ----------------------------- | --------: | --------: |
| 资源就绪、进入桌面            |  4,179 ms |  3,180 ms |
| 启动屏首帧                    |    137 ms |    142 ms |
| 页面 Resource Timing 压缩正文 | 734,333 B | 350,574 B |

该条件下进入桌面时间减少约 24%，页面记录的压缩正文减少约 52%。favicon 可能走浏览器独立缓存，不把它强行计入每次页面资源合计。此次结果不代表真机、Safari / Firefox 或其他地区网络；公网链路仍可能受代理、运营商和 CDN 路径影响，不能把不同时间的公网波动算作优化收益。
