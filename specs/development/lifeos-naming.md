# LifeOS 命名统一

2026-10-18。根据负责人本次要求，统一本项目的产品名称及派生代码标识；关联 #21 产品源码集成的命名维护。

## 最终约定

- 产品名称使用 LifeOS；npm 包名使用 lifeos，研究验证包使用 lifeos-validation。
- 系统模块位于 `components/system/LifeOS/`，公开资源位于 `public/System/LifeOS/`，共享样式为 `lifeos.css`。
- React 接口统一为 `LifeOSProvider`、`useLifeOS`、`LifeOSContext`、`LifeOSShell` 和 `canCloseLifeOSApp`。
- 站点配置使用 `lifeos.json`，站点生成脚本使用 `scripts/lifeos.cjs`。浏览器展示名称仍由该配置提供，为 Yincan Huang。
- 本地内容服务通过 `LIFEOS_PORT` 指定端口，默认仍为 4392。自定义启动命令需要使用新变量名。
- 正式源码、快捷方式、构建与审计脚本、端到端测试、文档和研究原型同步使用以上名称。上游 daedalOS 与第三方署名保持原样。
