# 系统级应用商店

2026-10-17 · 概念研究原型 · Issue #19（#9 的原生子 Issue）。

## 已确认需求与研究假设

负责人要求：增加系统级应用商店，管理原生、本站二开与第三方自建应用；先建立应用子 Issue 再开发原型。保留全部原 App，原生视觉、原生响应式、应用默认无设置按钮的约束继续生效。

URL 清单接入与本机应用库是本次**可撤回的研究方案，尚未经负责人确认**。代码包上传/执行、是否允许访客自建入口、站点级目录发布以及真正的安装/更新/卸载策略仍需评审。原型以可运行交互帮助作出决定，不将假设冒充既定产品规则。

## 信息架构与入口

开始菜单普通应用列表 → App Store → 全部应用 / 原生应用 / 本站二开 / 第三方 / 我的应用。商店只增加一个开始菜单快捷方式，不改变原桌面布局、不自动打开、不改变设置与 Power 的并列关系。窗口、最小化、最大化、任务栏、触屏操作沿用上游。

目录直接读取固定版本的 daedalOS process directory：保留 33 项上游注册，其中 5 项系统辅助进程不作为商店商品；28 项原生应用加作品集形成 29 项内置目录。SystemSettings 和 AppStore 为系统入口，不重复作为可安装商品。二开目前以作品集为首个示例，没有虚构尚未开发的 App。

部分原生应用是文件处理器，应先选择兼容文件，商店动作标为“选择文件”，打开 File Explorer，不承诺空窗口能直接使用。目录存在不等于每项功能或每个平台均已通过测试。

## 操作与权限

| 对象 | 本次原型操作 | 实际影响 |
| --- | --- | --- |
| 原生 / 本站二开 | 搜索、分类、详情、打开、加入/移出“我的应用” | 只改变商店快捷列表；不卸载代码、不禁用原始入口 |
| 自建网页应用 | 表单/JSON 清单添加、查看、打开、启用、停用、移除 | 当前浏览器与 origin 的应用库；新浏览器标签打开 |
| 站点公开目录 | 原型随构建提供 | 尚无 admin 上架、版本更新、审核或发布 API |
| 作品内容 | 沿用原权限 | 商店不获得内容写入能力 |

访客与 admin 均使用同一个本机入口管理原型；此处不是角色权限隔离设计已完成。admin 登录不会将本机应用发布给其他人，也不会使第三方应用自动获得管理权限。未来站点发布需独立授权、草稿/发布快照、审计、撤回和多节点一致性。

## 清单与持久化

```json
{
  "name": "我的应用",
  "nameEn": "My app",
  "url": "https://example.com/app",
  "description": "可选简介"
}
```

只接收上述字段，不接受脚本、权限或可执行包字段。HTTPS 外部地址限定，拒绝本站、显式本地/IP 地址、凭据 URL 和非 HTTPS 协议；不主动抓取任意 manifest URL，不执行导入内容。显示字符串走 React 文本输出；不加载用户自定义图标或 HTML。独立标签带 `noopener noreferrer`。这是导航入口，不是对第三方内容、域名解析、重定向或网络安全的认证，也不是 iframe 沙箱。

`hyc.app-library.v1` 为独立 localStorage 键，版本 1；最多 100 个网页入口。字段长度、重复 URL/ID、存储损坏均检查。读取失败不覆盖已有数据；写入失败不显示保存成功；storage 事件同步其他标签；写前检查原始值，降低覆盖风险。localStorage 不提供事务，同步更新的极端并发原子性不在原型承诺范围。

内置目录源于构建，不是远程商店分发包。移除网页入口也不删除其外部网站数据。没有自动更新、代码签名、包下载、卸载包和权限审批假功能。

## 页面与状态

列表：来源、名称、图标、简介、内置/已添加/已停用；搜索空状态。详情：来源、运行方式、目标网址（自建）、操作及影响说明。新增页：名称、英文名称、HTTPS 地址、简介；折叠 JSON 清单导入。存储失败、重复网址、无效清单、数量上限和跨窗口冲突给出可见错误；移除需确认。全部新界面中英双语，第三方描述保留用户原文，英文名称缺失回退原名称。

## 进入计划阶段的任务

- 确认自建应用是站长设计发布、访客本机添加，还是两者都支持；定义各自权限。
- 确认 URL 清单、跨源 iframe 与代码包各自适用范围；评估真实原生集成扩展契约。
- 设计 app ID、来源、版本、兼容版本、依赖、更新/回滚、授权和签名字段。
- 设计 admin 站点目录 CRUD、草稿、发布、下架、媒体管理与审计。
- 定义本机安装与上游打包目录、开始菜单、文件关联、桌面快捷方式的同步规则。
- 完成第三方隔离、重定向、失效站点、离线、跨标签并发和真实设备验收。
