# 验收矩阵与证据规则

2026-10-17 v1.1：A05/A06 按负责人反馈修订，旧自制三模式与 A/B 风格不再是验收目标。

以下为产品验收要求。研究原型的实际结果另外记录，不能仅因本表存在就勾选通过。

| 编号 | 验证任务 | 预期 |
| --- | --- | --- |
| A01 | 首次无参数访问 | 显示桌面，无作品集自动启动；原桌面和 App 入口仍在 |
| A02 | 显式原生 app/url 参数 | 原打开行为保留，作品集不抢占 |
| A03 | 作品详情直达、刷新、前进/后退 | 定位一致；不存在/未发布有明确状态 |
| A04 | 中文/英文、自动模式、刷新 | 优先级和保存正确；表单及窗口状态不丢失 |
| A05 | 原项目视觉一致性 | 字体、颜色、工具栏、选中态、滚动条与原项目一致；保留作品集 Web App 的业务与图文内容 |
| A06 | 多设备与上游对照 | 保留原桌面、任务栏与窗口规则；无额外设备判断/全屏样式/底部导航/模式设置；旧偏好不恢复已作废方案 |
| A07 | 原生文件工具、编辑器、游戏等 | 清单保留；实际运行结果逐项登记；特殊设备依赖不伪报通过 |
| A08 | OS 级设置与单密钥管理 | 开始菜单左侧栏→系统设置；作品集无设置按钮；单实例可恢复；展开菜单不清会话；语言和单密钥登录/注销可用 |
| A09 | 双语创建/编辑/排序/媒体/保存 | 草稿仅作者可见，另一语言输入保留 |
| A10 | 发布与草稿再次修改 | 访客看到已发布快照；草稿不会自动公开 |
| A11 | 下架 | 列表/详情/媒体新请求不可公开访问；缓存策略有验证 |
| A12 | 未保存关闭、版本冲突 | 可取消离开；不静默覆盖他处的新版本 |
| A13 | 越权、字段泄露、恶意链接/媒体 | 服务端拒绝管理请求与私有数据读取；不是仅隐藏按钮 |
| A14 | 跨实例与重启 | 生产会话/数据按部署设计一致；原型内存会话不冒充通过 |
| A15 | 既有 hyc.ac 项目路径 | 无未批准破坏，DNS/路由和发布回退记录完整 |
| A16 | 界面与可访问性 | 键盘可达、焦点可见；缩放与设备表现沿用上游，实际局限登记；关键文案和输入有语义标签 |
| A17 | 内容与来源 | 作者项目/贡献不混淆；无虚构经历、技能评级或项目指标 |
| A19 | 商店目录与启动 | 分类、搜索、详情、原生应用启动；全部 33 注册项保留，辅助进程不冒充商品 |
| A20 | 本机应用库研究方案 | URL/清单添加、持久化、禁用/启用/移除、无效输入和存储错误；不改动作者公开内容 |
| A21 | 商店系统一致性 | 原生窗口、开始菜单入口、中英双语；地址图标与文字不重叠、工具栏控件不穿过分隔线；不增加应用设置按钮或移动外壳 |
| A18 | 构建与升级 | 固定 SHA、锁文件、环境、差异和测试结果可重现；升级与回退有记录 |

证据等级：源码核验、自动测试、真实浏览器交互、DOM 渲染图、浏览器仿真、真机与线上测量分别标注。DOM 渲染不能替代原生截图，仿真不能替代真机，上游 CI 不能替代本项目集成测试。

性能验收先测量实际启动请求、缓存行为、作品 API 延迟和交互阻塞，再依据目标网络确认预算；不将仓库/构建目录总大小直接称为首屏下载量。重型原生应用的按需加载与作品集初始加载分别记录。

概念交付检查：PRD、内容/权限、流程/状态、UI 规范、架构决策、验收矩阵、计划任务、运行原型与已知限制均有可访问入口；未完成的生产项有明确任务，不以概念阶段名义宣称已上线。
