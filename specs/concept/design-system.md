# 作品集 UI 规范与两套设计方案

版本：1.0 概念交付稿。目标是为后续业务 App 提供可复用的设计语言；原生 App 继续保留自己的既有交互，第一版不以统一皮肤为由大规模重写它们。

## 设计方向

参考 DhirajOS 的是信息结构：进入后有明确内容窗口、介绍与项目入口、源码/体验行动、作品状态的区分。负责人明确不喜欢 Win98 风格，因此不采用像素字体、厚立体边框和复古按钮。窗口容器、任务栏与桌面行为使用 daedalOS，作品集内容采用现代、克制的桌面软件视觉。

| 方案 | 结构 | 适合任务 | 取舍 |
| --- | --- | --- | --- |
| A 原生工作台 | 侧栏＋紧凑作品行，封面为小预览，信息密度较高 | 快速比较项目、管理较多作品、后续工具型 App | 展示感较弱；视觉层级依赖排版与行间距 |
| B 现代陈列 | 同一侧栏＋简短介绍＋双列封面卡片，详情使用图文层级 | 首次认识作者、浏览少量精选开源项目 | 占用更多空间，需要让首屏行动明确，避免装饰挤压作品 |

两套共用内容模型、导航、表单、按钮、色彩和状态，不分叉业务逻辑。建议 B 作为作品集默认布局，A 作为对照和未来管理/工具 App 参考；负责人尚可在原型中选择，不能把建议写成已确认的审美决定。

## 基础规则

| 项目 | 建议令牌/规则 |
| --- | --- |
| 主色 | #3569D8，用于主要行动、选中导航与焦点，不为每个按钮引入不同颜色 |
| 浅色表面 | 背景 #F7F9FC、内容 #FFFFFF、侧栏 #EEF2F8、边线 #E1E7F0 |
| 深色表面 | 背景 #151C28、内容 #1E2836、边线 #303E52；需要逐状态校验，不只反转颜色 |
| 文字 | 主文字 #1D2A3D / 深色 #E7EDF7；次级文字有足够对比，不以浅灰充当装饰性正文 |
| 字体 | 系统字体栈，Segoe UI / 系统中文字体；不为首次访问强制下载大型中文字体 |
| 字号 | 阅读正文 13–15px、表单/导航 12–14px、页面标题 28–36px；装饰标签与正文分开处理 |
| 间距 | 4px 基础单位；8/12/16/24/32 为主要层级；表单和移动触控按可操作性增加间隔 |
| 圆角 | 按钮/输入 6–8px，卡片 10–12px；手机抽屉/启动卡 20–24px |
| 阴影 | 仅窗口、抬升卡片和浮层；普通列表依靠边线和底色分组 |
| 动效 | 短时反馈，不阻塞操作；尊重 reduced-motion，语言切换不播放整页离场动画 |

项目封面的蓝/紫/青/暖色仅用于作品识别，不表达发布状态。发布、草稿、错误和禁用使用一致的状态系统，同时提供文字，不能只靠颜色。

## 可复用模式

- **AppFrame**：左侧导航、顶部位置提示、独立可滚动内容区。外部窗口由 daedalOS 管理，App 不再套一个仿窗口标题栏。
- **Action**：主要操作一处突出，次要操作低强调，危险操作使用文字与确认；图标按钮有可访问名称。
- **ProjectCard / ProjectRow**：统一归属、标题、摘要和技术标签；整个卡片可以进入详情，源码/网站按钮放详情，避免卡片内嵌套点击冲突。
- **DetailLayout**：返回入口、封面、归属/标题/摘要、源码/网站、背景/贡献/技术；缺失可选字段隐藏，不展示假履历。
- **FormField**：标签、字段、必要的说明、错误；语言字段明确当前语言且保留另一语言已输入值。
- **EditorActions**：保存草稿、发布已保存版本、下架；未保存状态可见，发布前要求先保存，版本冲突不自动覆盖。
- **StatePanel**：加载、内容为空、搜索无结果、详情不可用、连接失败，分别给出不同原因和恢复行动。
- **SettingsSection**：语言/地区、外观/显示模式、折叠的站点维护；管理密钥入口不出现在作品集首页。

这些是设计模式，不要求原型阶段先建设独立组件库或发布 npm 包；应先让作品集与设置实际复用，再逐步抽取。

## 交互细节

导航状态和“当前位置”一致；返回列表时应保留筛选与滚动位置。首次进入自动打开作品集，但显式 `app/url` 原生应用链接优先。作品集关闭后不会立刻自动弹回；桌面、任务栏或移动启动卡可以恢复它。

源码、项目官网、文档和实际 Demo 使用准确标签。未经实测的官网不标为“可在线试用”。外链打开新标签，当前作品集状态保留。

管理表单使用正常阅读顺序。语言切换改变编辑字段的语言视图，不能丢弃另一语言输入；原生窗口关闭、返回预览、浏览器离开均需考虑未保存内容。发布/下架后给出明确成功反馈，同时更新公开状态。

## 多端设计

- 桌面保留 daedalOS 多窗口与任务栏；作品集侧栏可见，封面卡双列，原有桌面不重排，仅新增必要入口。
- 手机作品集全屏呈现，App 内底部导航与 OS 导航职责分开；卡片单列、返回清楚，所有关键行动无需拖拽窗口。
- 平板保留侧栏和较大的内容区；应用默认最大化，支持触摸和外接键盘；横竖屏切换不重置当前内容。
- 自动适配看视口与输入能力，不把语言当地区、不把 UA 字符串当唯一依据。系统设置允许手动覆盖显示模式。

## 内容与视觉资产

当前原型使用项目名称与自绘抽象封面，不将示意图伪装成项目真实截图；管理员可上传真实封面。初始公开资料来自本人 GitHub 主页及其列出的项目。不得补造头像照片、公司经历、项目收益或个人贡献。

原生截图通道在本环境超时，研究证据采用 DOM 渲染图与真实页面几何/交互记录；不能把 DOM 图当成跨浏览器或真机视觉验收。最终发布还需要浏览器缩放、触控、字体差异和辅助技术检查。
