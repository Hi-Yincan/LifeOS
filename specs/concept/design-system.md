# 作品集 UI 规范：与 daedalOS 保持一致

版本：1.3 · 2026-10-17。负责人明确保留现有 Web 应用，只修改视觉，并取消额外手机/平板适配。本文替代 2026-10-16 的 A 原生工作台 / B 现代陈列方案；旧图留档，不再作为当前候选。

## 应用形式与内容

作品集是注册在 daedalOS 中的 React Web App，由原生进程/窗口体系承载。无需改造成原生二进制、文件管理器或外部站点 iframe。概览、作品列表、分类/搜索、图文详情、关于与联系、单密钥管理和双语内容继续保留。

此前视觉问题来自独立的品牌侧栏、宣传式大标题、彩色装饰封面、大圆角、留白与独立浅/深皮肤。只复用窗口外框不足以形成整体一致性。本次移除这些装饰，统一应用内控件，保留作品展示所需的图文与真实上传图片。

## 直接复用与样式来源

参考固定上游 `f017b393d4175eb396a741a7562299423843f1b1`，不凭印象重新造一套“Windows 风格”。

| 项目 | 实现依据 |
| --- | --- |
| 系统字体 | `theme.formats.systemFont`，继承 daedalOS ThemeProvider |
| 文本/高亮/选中颜色 | `theme.colors.text/highlight/fileEntry` |
| 工具栏 | 直接使用 `components/apps/FileExplorer/StyledNavigation` |
| 位置栏 | 直接使用 `StyledAddressBar`，显示作品集位置，不冒充文件系统路径 |
| 返回图标与按钮 | 上游 `NavigationIcons.Back`、`styles/common/Button` |
| 状态栏 | 直接使用 `Files/FileManager/StyledStatusBar` |
| 滚动条 | 直接使用 `styles/common/ScrollBars` |
| 窗口、标题栏、任务栏、开始菜单 | 继续由上游管理，不覆盖尺寸/位移或替换移动导航 |
| 应用中性表面 | 与 File Explorer 一致：内容 #202020、工具栏 rgb(25 25 25)、状态栏 rgb(51 51 51)、边框 rgb(83 83 83) |

File Explorer 只作为原项目自有控件的视觉参照，不要求作品集复制文件操作语义。按钮、字段、图文卡片与详情仍服务作品阅读和管理。当前上游 File Explorer 使用深色中性表面；设置中移除仅影响新 App 的独立皮肤开关，避免伪称全 OS 主题切换。

## 页面与状态

- 概览：紧凑作者简介、精选作品；无营销式装饰插画或重复品牌区。
- 导航：保留概览/作品/关于，采用原生选中态、字号和紧凑间距；顶部位置栏与返回按钮，底部显示作品数/管理状态。
- 作品卡片：方形边界、中性底色、项目名称与摘要；真实上传媒体保留。未上传封面用简单标识，不制造大型宣传封面。
- 详情：项目背景、贡献、媒体、技术与源码/网站入口照常展示；标题层级清楚，但不使用独立品牌页面皮肤。
- 管理：保留双语字段、上传、排序、草稿、发布和下架。字段、焦点和按钮与同一视觉系统一致。
- 系统设置：从开始菜单左侧栏独立按钮打开，应用默认不带设置按钮，负责人明确指定时才例外。系统窗口提供语言/地区与折叠维护入口；不再出现 A/B 布局、手机/平板/桌面模式或独立皮肤选择。
- 状态：空、加载、错误、草稿、已发布和未保存均提供文字；原有关闭保护、权限和发布规则不因换肤改变。

## 响应式边界

所有设备沿用 daedalOS 的原生桌面、任务栏、窗口适配和 viewport。应用内容仅根据已有窗口可用空间自然排列和滚动，不检测设备类别、不强制全屏、不改变系统导航、不使用独立手机或平板样式。

新增样式限制在 `.hyc-surface` 内容或对应 styled-component，禁止全局覆盖 `.react-draggable`、原生任务栏、窗口 transform 或上游 App。旧本地偏好只迁移作者 App 自有字段，不清除原项目会话和文件。

## 验收依据

将作品集与同一构建内的 File Explorer 对照：字体、表面、工具栏/状态栏高度、边框、选中态和滚动条有源码来源，并通过实际页面复核。检查概览、详情、设置和编辑器；同时验证小尺寸仍使用上游任务栏/窗口，以及旧偏好不能恢复作废方案。

DOM 渲染图属于视觉研究证据，不替代原生截图或真机验收。历史 A/B 图与三模式图保留在旧报告中，并明确标注已被本版取代。

系统入口与例外规则见 [系统设置规范](system-settings.md)。
