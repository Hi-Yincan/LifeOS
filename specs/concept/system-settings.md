# 系统设置与应用设置边界

2026-10-18 · v1.5。设置仍是开始菜单独立入口，按用户最新决定移除站点维护与登录功能。

## 入口

**开始菜单左侧栏 → 系统设置**。左栏顶部保留 START 与 All apps，底部仅保留系统设置、Power，系统设置排列在 Power 上方。

- 复用原生 SidebarButton 的图标尺寸、悬停、折叠/展开、键盘行为与行高。
- 点击直接打开独立的系统设置窗口，不打开电源子菜单。
- Power 保持上游原始功能与提示，不承载设置入口，不改变它的行为。
- Documents、Pictures、Videos 在所有视口均不显示于侧栏；文件夹本身与文件管理器访问能力保留。窗口和响应式继续沿用上游。
- 普通应用列表不重复放 Settings 快捷方式；应用内默认不带设置按钮，负责人明确要求时才例外。

## 职责与权限

系统设置负责本机 OS 语言和时区。所有浏览者使用同一设置界面，不提供站点维护、密钥输入、登录、登出或管理状态。作品集和看板仅供阅读；站长的内容维护转到独立信息源系统，见 [信息源管理报告](../architecture/source-managed-content.md)。

后续自研 App 默认无设置按钮。例外必须在对应 spec/Issue 记录负责人明确要求。已保留的上游第三方 App 不在本次范围内批量改写菜单。

## 验收

1. 开始菜单左栏顶部为 START、All apps，底部顺序为系统设置、Power；折叠与展开均不显示 Documents、Pictures、Videos。
2. 设置按钮折叠时显示齿轮，展开时显示名称；鼠标或键盘可直接打开系统设置。
3. 设置可关闭、最小化、恢复，重复打开仅保留一个实例。
4. 作品集没有设置按钮，Start Menu 普通应用列表没有本项目生成的 Settings 快捷方式。
5. Power 的原始回调及提示通过源码比较保持一致；不为验证而执行清除既有浏览器会话的操作。
6. 语言切换与当前时区显示继续可用；不存在维护入口和密码框，不发起 `/api/session` 请求；构建和浏览器检查留档。
