# 系统设置与应用设置边界

2026-10-17 · v1.2 概念修订。负责人确认新版原生视觉方向，并要求设置为 OS 级入口；应用默认不带设置按钮，只有负责人明确说明时例外。

## 入口与职责

唯一常规入口：**开始菜单 → 电源按钮 → 系统设置**。

- 系统设置是独立系统窗口，管理 OS 语言/地区和折叠的站点维护入口，状态不属于作品集。
- 作品集工具栏、侧栏都不显示设置按钮；不在普通应用列表中重复放置本项目的 Settings 快捷方式。
- 作品集的浏览、分类、搜索、编辑、保存和发布属于业务操作，继续保留在应用内。
- 后续自研应用默认遵循同一规则，不自动添加齿轮按钮。确需应用专属设置时，在该应用的 spec/Issue 中记录负责人明确要求，再设计入口与范围。
- 本轮修改自研作品集与系统入口；已保留的上游第三方应用继续使用原有功能，不借此批量删除其内置菜单。

## 电源菜单

使用 daedalOS 原生菜单组件；点击电源先展开菜单，提供“系统设置”和“清除会话并重新加载”。原电源按钮的清除会话函数保留为明确菜单项，不伪装成无副作用的页面刷新。打开菜单或系统设置本身不执行清除操作。

菜单应支持鼠标和键盘；Escape 关闭。菜单定位与越界处理沿用上游。系统设置已打开时再次选择恢复并聚焦同一窗口，不创建副本。无需修改原生多设备响应式。

## 作者管理

路径：开始 → 电源 → 系统设置 → 展开站点维护 → 单密钥验证。系统设置内继续保留语言选择、进入管理、内容管理和退出管理；成功验证后的会话仍由服务器控制。入口迁移不改变权限、内容、发布流程，也不建立用户名账户。

## 验收

1. 作品集概览、列表、详情和编辑页面无设置按钮；默认规范适用于后续自研 App。
2. 从电源菜单可以打开系统设置，普通 Start Menu 应用列表没有本项目生成的 Settings 快捷方式。
3. 仅展开电源菜单不会重载或清除会话；原清除功能保留正确回调。
4. 系统设置可关闭、最小化、恢复；重复打开只存在一个实例；键盘可打开菜单并选择设置。
5. 语言切换及单密钥进入/退出管理仍可用；作品集不需要提供系统设置入口。
6. 固定 SHA、应用保留清单、补丁清单、构建及浏览器结果有留痕。测试不实际执行清除现有浏览器会话的菜单项，其回调通过源码核对。
