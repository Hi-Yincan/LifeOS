# 系统级应用商店：研究原型与验收

2026-10-17 · Issue #19，父 Issue #9 · 草稿 PR #16。

## 交付

先建立 #19 并通过 GitHub sub-issue API 挂到 #9，再开发原型；首条 C28 评论记录范围与待决项。Issue 主体维持目录。原型从开始菜单 App Store 进入，使用 daedalOS 原生进程、窗口、图标、工具栏、状态栏和系统主题。

- 28 项原生应用＋个人作品集，共 29 项内置目录，支持来源分类、搜索、详情、启动及商店内收藏。
- 全部 33 项上游注册内容逐字保留；5 项系统辅助进程不作为商品展示。文件处理器以“选择文件”进入 File Explorer。
- 实验性第三方入口支持表单与 JSON 清单添加、持久化、启用/停用、两步确认移除；外部 HTTPS 应用在独立标签打开。
- 本机应用库不修改作者公开内容，不伪装成代码包安装/卸载，也不提供站点目录发布。
- 商店内部中英双语，入口和窗口沿用 OS；桌面布局与设置侧栏、Power 行为无新增改动，没有商店设置按钮和额外移动外壳。

详细规格：[app-store.md](../../specs/concept/app-store.md)。

## 待评审与未完成的能力

URL 清单和本机管理仍是研究假设；负责人尚未确认是否需要上传代码包、是否允许访客自建入口，以及 admin 如何全站上架。当前不包含真实包安装、签名、依赖、升级/回滚、iframe 沙箱、站点级目录 CRUD/发布和第三方审核。不能据此声称成熟应用分发平台已完成。

所有原生 App 均保留，不代表全部逐项功能验收；此次重点启动检查 Paint 与作品集。静态导出 headers 警告仍在；本地服务能力不代表 GitHub Pages 全部运行时兼容。真手机/iPad、离线、浏览器存储配额、极端并发、多地区网络和生产权限隔离留待计划阶段。

本次没有改动现网、域名、DNS 或服务器部署，也未合并草稿 PR。原型仍位于本地 4391 端口。
