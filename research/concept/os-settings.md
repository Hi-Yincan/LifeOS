# OS 级设置入口修订

2026-10-17 · 按负责人确认落实：保留当前原生视觉方向，设置属于 OS；应用默认不带设置按钮，明确要求时才例外。

## 变更

- 入口为 **开始 → 电源 → 系统设置**。设置作为独立系统窗口，继续提供语言/地区与折叠的站点维护（单密钥登录/退出）。
- 移除作品集工具栏和侧栏的设置按钮；移除之前生成的普通 Start Menu 应用列表 Settings 快捷方式。
- 原电源按钮会直接调用上游 `setHaltSession(true)` 与 `resetStorageAndReload(rootFs)`；现在点击先打开原生菜单，原回调保留在“清除会话并重新加载”项下。单纯打开菜单/设置不执行清除。
- 新菜单复用上游 Menu 的定位、越界、选中态与键盘处理，设置窗口通过原有单实例启动器打开/恢复。
- 既有原生 App 保留。本轮不批量改写第三方应用的内置菜单。后续自研 App 默认无设置入口；例外须由负责人明确提出并在对应 spec/Issue 记录。
