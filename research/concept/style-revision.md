# 2026-10-17 概念修订：沿用原生响应式，统一应用视觉

状态：负责人已认可本轮原生视觉方向。设置入口已按负责人截图纠正为开始菜单左侧栏的独立按钮，见 [系统设置入口](sidebar-settings.md)；本报告中的应用设置按钮属于当时实现。此报告替代 2026-10-16 的独立 A/B 风格和额外手机/平板模式；原报告与图片保留为历史记录。

## 已确认的变更

1. 取消额外手机、平板适配，所有响应式行为参考 daedalOS 原项目，保持整体一致。
2. 保留当前作品集 Web 应用，仅修改视觉。负责人明确说明可以继续使用这个 Web 应用，不需要因为视觉不一致而换技术或改造成文件管理器。

## 实际修改

- 保留 React App 注册、原生窗口/进程接入、内容 API、双语内容和单密钥管理流程。没有新增 iframe 或外部站点套壳。
- 删除自制手机桌面、应用抽屉、底部系统导航、全屏/窗口位移覆盖、设备判断与模式选择；也移除原先浮在原生任务栏上的自制快捷按钮。
- 恢复原项目 viewport，保留原生任务栏、Start Menu、桌面图标与窗口拖动/缩放/最大化。作品集和设置仍可通过已有新增的 Start Menu 快捷方式及 App 内入口打开。
- 清理旧的 device/theme/layout 偏好，只保留有效语言选择；不清除原 OS 会话或浏览器文件。
- 作品集和设置使用上游系统字体、主题文本/高亮/选中颜色与滚动条；直接复用 File Explorer 工具栏、位置栏、返回按钮和状态栏的样式组件。
- 移除网站式品牌侧栏、大型标语插画、彩色装饰封面、大圆角与独立皮肤。概览、作品卡片、图文详情、关于、上传与管理功能保留。
- 独立 App 的浅/深皮肤和 A/B 开关退役。此处并没有新增全 OS 主题系统。
